# Room schemas

This directory holds the exported Room schema JSON for `AppDatabase`, one file per database version:

    io.github.gonbei774.calisthenicsmemory.data.AppDatabase/<version>.json

The files are inputs to `MigrationTestHelper` (the `androidTest` source set adds this directory to its assets) and are the evidence behind the supported-version policy in `docs/development/supported-database-versions.md`.

## Rules

- Never hand-edit a schema file. Every file is produced by the Room compiler from the entities of the commit listed below.
- A committed schema is immutable. If the entities change, bump the database version, add a migration, and commit the new version's schema alongside the existing ones.
- Only the current version's file is generated by the build (`room.schemaLocation` in `app/build.gradle.kts`). Historical files are recovered once from their own commits and never regenerated from current sources.
- Run `scripts/check-room-schemas.sh` after changing entities. It regenerates the current schema and fails when any committed schema changed, when a new schema file appears, when a file's `database.version` does not match its name, or when the current schema's identity hash differs from the generated `AppDatabase_Impl`. CI runs the same script.
