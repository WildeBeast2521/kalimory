# Workouts

Every way of training saves the same kind of workout, so your history, graphs and progressions see all of them.

## Single exercise

Start one exercise from Train › Quick start. For reps, the app can count out loud with the count sound. For holds, it times each set. Between sets it counts down your rest.

## Programs

A program is a list of exercises with their sets, run in order. Create one in Library › Programs. While it runs, the overview lets you jump to another exercise, redo a set or skip one.

You can save a program part-way through and finish it later. Only one workout can be saved at a time.

## Interval routines

Timed rounds of work and rest, for example 30 seconds on and 15 seconds off. Create them in Library › Interval.

## Log a past workout

Train › Log a past workout records sets you already did, with their date and time. Use "Add another exercise" to put several exercises into one workout.

## If the app is closed during a workout

Timers keep running in a notification. If the app is stopped anyway, Today offers to continue where you left off.

## Sounds and vibration

Settings has the sound options for counting and rests, and "Vibrate When a Set Is Done".
